# Product Requirements — TrailBro

A browser-based sim racing pedal telemetry viewer that displays live gamepad input (brake, throttle, steering) with a dark-themed UI.

## Goals
- Provide real-time visualization of sim racing pedal and steering inputs
- Support any gamepad/controller via the Web Gamepad API
- Zero setup: open the browser, connect a controller, go

## Non-Goals
- No account system, no cloud sync
- No AI coaching or training gamification
- No backend server — fully client-side
